# Markdown 编辑器辅助编辑工具栏 — 需求文档

> 文档状态：已实现（2026-09-20）
> 涉及模块：`rustgpui/src/ui/editor.rs`（EditorPanel）
> 关联技术栈：GPUI / gpui-component（`Textarea`、`Button`、`Icon`）

---

## 1. 背景与目标

当前 Markdown 编辑器仅提供纯文本输入，用户插入表格、图片、列表等常见结构时需要手动记忆并输入 Markdown 语法，效率较低且易出错。

**目标**：在编辑器顶部提供一个集中的快捷工具栏，将常用 Markdown 编辑操作以「图标按钮 + 悬停提示」的方式呈现，使用户无需记忆语法即可快速完成编辑，同时保持工具栏紧凑、不喧宾夺主。

**验收目标**：
- 打开笔记时显示工具栏，未打开笔记时不显示。
- 每个操作均可通过一次点击完成插入或包裹。
- 工具栏按钮为纯图标，鼠标悬停时显示该功能的中文说明。
- 操作不会破坏编辑区焦点与选区，且能正确触发自动保存。

## 2. 功能需求

### 2.1 工具栏入口
- 工具栏仅在「已打开笔记」时渲染（基于 `self.note.is_some()`）。
- 位于编辑区上方、状态栏上方的横向条带，支持换行（`flex_wrap`）。

### 2.2 支持的编辑操作
工具栏共提供 13 个操作，按用途分组（组间以分隔线区分）：

| 分组 | 操作 | 功能说明 | 插入/包裹行为 |
| --- | --- | --- | --- |
| 行内标记 | 加粗 | 包裹选中文本，或插入 `**` 标记 | `**…**` |
| 行内标记 | 斜体 | 包裹选中文本，或插入 `*` 标记 | `*…*` |
| 行内标记 | 删除线 | 包裹选中文本，或插入 `~~` 标记 | `~~…~~` |
| 行内标记 | 链接 | 包裹选中文本为链接，无选中则插入占位 | `[…](url)` |
| 行内标记 | 图片 | 包裹选中文本为图片，无选中则插入占位 | `![…](url)` |
| 块级结构 | 标题 | 在当前行行首插入 `# ` | `# ` |
| 块级结构 | 无序列表 | 在当前行行首插入 `- ` | `- ` |
| 块级结构 | 有序列表 | 在当前行行首插入 `1. ` | `1. ` |
| 块级结构 | 任务列表 | 插入任务待办项 | `- [ ] ` |
| 块级结构 | 引用 | 插入引用块前缀 | `> ` |
| 块级结构 | 代码块 | 插入围栏代码块，光标置于块内 | ```` ``` ```` |
| 块级结构 | 表格 | 插入 2 列 Markdown 表格模板 | `| 列1 | 列2 | …` |
| 块级结构 | 分割线 | 插入水平分隔线 | `---` |

### 2.3 两种插入模式
- **行内包裹（surround）**：适用于加粗、斜体、删除线、链接、图片。
  - 有选区：将选区整体包裹（`before + 选中文本 + after`）。
  - 无选区：插入前后标记，并把光标落在两个标记之间，便于直接输入。
- **块级插入（block）**：适用于标题、列表、引用、分割线、代码块、表格。
  - 若光标不在行首，先补一个换行使其自成一块，再插入对应前缀/模板。
  - 代码块与表格会把光标定位到「空内容区」（代码块内部、表格首个数据单元格），方便继续输入。

### 2.4 焦点与选区保持
- 工具栏按钮使用 GPUI 原生按钮，点击时**不会抢走编辑区焦点**，因此点击前在编辑器中选中的文本在点击后仍有效，可直接被包裹。
- 操作完成后调用 `state.focus(window, cx)` 重新聚焦编辑区，使光标可见，保证后续输入落在笔记内。

### 2.5 自动保存联动
- 所有插入均通过 `EditorState` 的 `insert` / `replace` 完成，这些方法会触发 `Change` 事件，从而驱动既有的自动保存逻辑，无需额外处理。
  （2026-10-20 注：编辑内核已由 `TextareaState` 升级为 `EditorState`，见 `docs/editor/editor-core-migration-eval.md`；本需求的接口名随之变更，行为不变。）

### 2.6 状态栏反馈
- 每次操作后在底部状态栏显示「已插入：<操作名>」，操作名复用 `Format::label()`（如「加粗」「表格」）。

## 3. 交互与视觉设计

### 3.1 按钮形态
- 按钮为**纯图标按钮**（不显示文字标签），采用 `.small()` + `.ghost()` 样式，悬停高亮，整体紧凑。
- 图标与文字标签二选一时，最终选择隐藏文字、仅保留图标，以避免占用横向空间。

### 3.2 图标方案
- 由于默认图标集不含 bold/italic/table 等语义图标，所有图标使用**内联 SVG**（Lucide 风格，24×24，`stroke="currentColor"`，`fill="none"`）。
- 通过 `Icon::data(&[u8])` 以字节形式内联，无需向资源包注册新图标。
- 图标颜色随主题文字色变化，亮/暗主题均清晰可见。
- 每个 `Format` 变体在 `format_icon()` 中映射到对应 SVG（加粗 `B`、斜体 `I`、删除线、标题 `H`、各类列表、引用、代码块 `</>`、表格、链接、图片、分割线）。

### 3.3 悬停提示（Tooltip）
- 每个按钮通过 `.tooltip(...)` 配置悬停提示，**提示文案以功能名称开头**，例如：
  - `加粗：包裹选中文本，或插入 ** 标记`
  - `标题：插入 # 标题行`
  - `任务列表：插入待办项 - [ ]`
  - `表格：插入 Markdown 表格模板`
  - `分割线：插入 --- 水平分隔线`
- 用户未悬停时界面不显示文字，悬停即可直观了解按钮功能。

## 4. 技术实现要点

| 项目 | 说明 |
| --- | --- |
| 操作枚举 | `enum Format { Bold, Italic, … }`，含 `label()` 返回中文名 |
| 图标映射 | `fn format_icon(cmd: Format) -> Icon`，内联 SVG 字节 |
| 行内包裹 | `fn surround(state, before, after)`：有选区包裹、无选区置中 |
| 块级插入 | `fn block(state, text)`：非行首先换行，再插入 |
| 代码块/表格 | `code_block()` / `table()`：插入模板并把光标定位到空内容区 |
| 行首判断 | `fn at_line_start(state)`：偏移为 0 或前一字符为 `\n` |
| 按钮构建 | `toolbar_button(id, tooltip, cmd, cx)`，仅 `.icon()` + `.tooltip()` |
| 入口 | `render_toolbar()`，仅在 `note.is_some()` 时调用 |

**关键约束 / 注意事项**：
- `Button::icon` 接受 `impl Into<Icon>`，自定义 SVG 经 `ButtonIcon` 接入，库内已有测试覆盖该路径。
- 内联 SVG 使用 `currentColor`，由 `Icon` 的 `text_color` 解析主题色。

## 5. 验收标准

1. 打开任意笔记 → 工具栏出现；关闭/未打开笔记 → 工具栏隐藏。
2. 选中一段文字后点击「加粗」→ 文本被 `**` 包裹，焦点仍在编辑区。
3. 无选区时点击「链接」→ 插入 `[ ](url)`，光标位于方括号内可输入文本。
4. 点击「表格」→ 插入 2 列表格模板，光标位于首个数据单元格。
5. 按钮无文字标签；鼠标悬停任一按钮 → 显示以功能名开头的中文说明。
6. 操作后底部状态栏提示「已插入：XXX」。
7. 所有操作编辑区出现变更后，自动保存照常触发。

## 6. 后续可优化项

- **可访问性**：为图标按钮补充 `aria-label` / 键盘快捷键（如 `Ctrl+B`），便于无鼠标操作。
- **图标尺寸/间距**：提供配置项调整图标按钮大小与工具栏间距。
- **更多操作**：撤销/重做、行内代码、数学公式、脚注等可继续扩充 `Format` 枚举。
- **自定义图标**：若后续默认图标集补全语义图标，可将内联 SVG 替换为资源包图标，统一维护。
