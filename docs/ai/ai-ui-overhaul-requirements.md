## 1. 背景与目标

### 1.1 现状（全部附证据）

AI 交互界面由 4 块组成，其中对话条是**编辑器内嵌块**，不是 Dock 面板、不是浮层：

| 组成 | 位置 | 形态 |
|---|---|---|
| AI 对话条 `AiChat` | `src/ui/ai.rs`（1828 行） | **嵌在 `EditorPanel` 内**（`editor.rs:2993-2998`），每个笔记标签一份实例 |
| AI 修订评审条 | `src/ui/editor.rs:2096-2280` | 嵌在正文上方（`editor.rs:2986-2989`） |
| 库级任务计划面板 | `src/ui/ai/plan.rs`（623 行） | `open_dialog` 浮层（`plan.rs:86-100`） |
| 命令面板 AI 条目 | `src/ui/command.rs:383-404` | `open_dialog` 浮层（`command.rs:350-363`） |

面板注册表（`src/main.rs:21-38`）里**没有任何 AI 面板**；Dock 布局为「左文件树 260 / 中编辑器 / 右预览 420」（`app.rs:752-755`）。

问题清单（这就是"粗糙"的具体所指）：

| # | 问题 | 证据 |
|---|---|---|
| P1 | **AI 区是全项目唯一零 hover 态的交互区** | `.hover(` 全项目 7 处（outline/search/backlink/tags/rail/settings），`ai.rs` 与 `ai/plan.rs` 各 0 处；`ai.rs` 只有 3 个 `cursor_pointer`（`1490`/`1507`/`1559`） |
| P2 | **AI 区是全项目唯一手搓颜色的地方** | `bubble_bg()` 用 `hsla()` 写死用户气泡底色（`ai.rs:64/66/74-81`）；其余全项目只有 `core/highlight.rs:380` 的 syntect 转换 |
| P3 | 尺寸全是魔法数字 | `HISTORY_MAX_H 260`（`ai.rs:52`）、`BODY_MAX_H 220`（`:57`）、`BUBBLE_MAX_W 0.78`（`:59`）、`BUBBLE_RADIUS 12`（`:61`，注释承认不跟主题）、`plan.rs:30-33`、`command.rs:29-33`、`editor.rs:40-44` |
| P4 | 间距不成体系 | 同一文件五段四种组合：顶栏/输入行 `gap_2`，对话区/动作行 `gap_1`，气泡 `px_3 py_2`，底部 `pb_1`/`pb_2` 混用（`ai.rs:1376/1453/1505/1637/1665/1760`） |
| P5 | AI 回复气泡**无背景、无边框、无头像、无角色标识**，只靠左右对齐与用户气泡区分 | `ai.rs:1512-1514` |
| P6 | `AiMode`（Chat/Action/Skill，**`ai.rs:190-200`**）没有任何切换控件，用户不知道自己在哪种模式 | 渲染里无出口 |
| P7 | 状态行是纯文本堆叠：`text_xs` 的耗时 / tokens / 工具次数 / 错误全挤一行，无图标、无分隔 | `ai.rs:1760-1807` |
| P8 | 命令面板条目**无图标、无键位提示**；全项目无 `kbd` 实现，键位只能靠 `tooltip_with_action` 文案（`editor.rs:2627-2631`） | `command.rs:259-278` |
| P9 | 对话条**不可调高**（`max_h` 写死 260），也不可停靠/最大化 | `ai.rs:1448`；`drawer.rs:109` 的抽屉同样 `resizable(false)` |
| P10 | 顶栏只有一条 `border_t_1`，对话区与输入行之间**无分隔**；根容器无边框/圆角/阴影 | `ai.rs:1379`、`ai.rs:1809-1821` |
| P11 | AI 工具栏按钮没有"对话条已打开"的选中态（有 `ai_open` 状态但没渲染成 active） | `editor.rs:2623-2634` |
| P12 | `editor.rs:1676-1679` 开关 AI 条时用 `eprintln!` 打日志（调试残留） | — |

### 1.2 目标

| # | 目标 | 衡量 |
|---|---|---|
| G1 | 建立可复用的视觉规范：配色 / 字号 / 间距 / 圆角 / 图标，消除魔法数字与手搓颜色 | 气泡底色走主题 token；尺寸进常量表 |
| G2 | 层级与切换清晰：侧边栏、编辑器区、对话区三者边界明确、可切换 | 对话区形态按 §6-Q1 |
| G3 | 交互细节补齐：hover / active / focus 反馈、键位提示、命令面板图标与键位、可拖拽调高 | 人工逐条验 |
| G4 | 与既有面板、标签页、主题体系、明暗模式一致 | 切主题后 AI 区无一处脱离 token |
| G5 | 简洁克制、信息密度合理 | 人工验 |

## 2. 非目标

- **不动 AI 业务逻辑**：agent loop / 工具调用 / prompt 拼装 / 模型路由 / 会话落盘格式（`StoredBlock`）一律不改
- **不新增依赖**：只用现有 `gpui-kit 0.8` 能力
- **不做多会话列表 / 会话管理 UI**（除非 §6-Q4 选了全局会话）
- **不改预览区、文件树、大纲等既有面板的交互**（只保证 AI 区与它们视觉一致）
- **不做动画框架 / 自定义动效系统**

## 3. 功能模块

| # | 需求 | 说明 |
|---|---|---|
| R-1 | **视觉规范 token 化** | 建立 AI 区（可推广到全局）的间距 / 圆角 / 字号 / 语义色常量表，替换 `ai.rs` / `plan.rs` / `editor.rs` 里的魔法数字；`bubble_bg` 改为走主题 token（`accent`/`muted`/`surface` 体系），删掉 `hsla()` 手搓 |
| R-2 | **对话区形态与层级** | 侧边栏 / 编辑器 / 对话区的层级与切换方式，按 §6-Q1；若改成可停靠面板，需处理 Dock 布局版本与用户既有布局 |
| R-3 | **消息气泡重做** | 角色标识（图标或头像位）+ AI 侧容器背景 + 圆角跟主题 + hover 反馈 + 折叠/展开有明确 affordance + 流式生成中的指示（现在是单行 `text_xs`「生成中…」，`ai.rs:1761-1767`） |
| R-4 | **输入区重做** | 多行输入（`Textarea`，现状是单行 `Input`，`ai.rs:1669/`473`）+ 发送 / 停止 + **模式切换 UI**（Chat / Action / Skill 暴露出来，现状无出口）+ 快捷动作行的当前模式高亮 |
| R-5 | **快捷动作与状态行** | 快捷动作按钮补图标与键位提示；状态行改成分区（耗时 / tokens / 工具次数 / 错误各占一格，带图标与分隔），错误态用 `danger` 而非纯文本 |
| R-6 | **交互细节** | hover / active / focus 三态；命令面板条目加图标与右侧键位；对话条可拖拽调高（去掉写死 260）；AI 工具栏按钮补"已打开"选中态；删掉 `eprintln!` |
| R-7 | **明暗与主题一致** | 所有新增元素走 `cx.theme()`；切主题、切高亮主题（`core/theme.rs:22-35`）时 AI 区不脱队；评审条与库任务浮层同款 |
| R-8 | **评审条与库任务浮层**（范围见 §6-Q2） | 评审卡片补 hover 与选中态、圆角跟主题；`plan.rs` 条目改成真正的卡片（现状 `rounded(radius)` 但无底色，`plan.rs:505`） |

## 4. 边界与约束

逐条过边界九项：

| # | 边界项 | 判定 | 处理 |
|---|---|---|---|
| 1 | 空输入 | **适用** | 空对话要有空态容器（现状是裸 `text_xs muted`，`ai.rs:1456-1462`）；空提示词点发送不发起请求；空快捷动作列表不渲染空行 |
| 2 | 超大输入 | **适用** | 超长消息（上万字）与超长输出：气泡折叠阈值、滚动区 `max_h` 与渲染性能；会话落盘 `StoredBlock` 不受影响 |
| 3 | 非法路径 | 不适用 | AI 区无路径输入 |
| 4 | 并发写 | **适用** | 会话落盘走既有机制（切笔记 / 退出时写），重做 UI 不新增写盘时机 |
| 5 | 外部程序改文件 | 不适用 | — |
| 6 | 崩溃后半截文件 | **适用** | 会话 JSON 半截时 `ai_sessions` 加载失败要降级为空会话，不 panic（现状无测试覆盖，见 §5 风险） |
| 7 | 多库切换 | **适用** | 切库时：AI 会话、对话框开合状态、评审条状态都要重置；若对话区改成独立面板（Q1-B），面板状态跨库要保持 |
| 8 | 隐藏与忽略文件 | 不适用 | — |
| 9 | 非 UTF-8 | **适用** | 模型输出出现非法 UTF-8 时，气泡渲染不能 panic（`TextView::markdown` 的输入要兜底） |

补充约束：

| # | 约束 | 理由 |
|---|---|---|
| C1 | 消息块 `Block` 的 **序列化格式不得改** | `Block::to_stored/from_stored`（`ai.rs:300-364`）被 `tests/state/ai_sessions.rs` 与 `tests/ui/ai.rs:56-91` 锁死 |
| C2 | `bubble_bg` 若删除，**同步改 `tests/ui/ai.rs:97-119`** | 该测试直接断言 HSL 分量 |
| C3 | 命令面板 `AI: ` 前缀保留 | `tests/ui/command.rs:86-171` 断言 |
| C4 | 评审状态机（`AiReview`/`HunkState`/`ReviewBlock`）不改语义 | `tests/ui/editor.rs:406-505` |
| C5 | 若动 Dock 布局（`MAIN_DOCK_VERSION = 6`，`app.rs:492`） | 用户既有布局会被重置，必须在文档与验收里写明 |
| C6 | 不在 `tests/` 根新增文件 | `Cargo.toml:13` `autotests = false`，靠 `#[path]` 挂载 |

## 6. 决策记录（2026-10-29 用户已拍板，G1 通过）

| # | 问题 | 结论 |
|---|---|---|
| Q1 | 对话区形态 | **保持编辑器底部内嵌条**，只重做视觉与交互：不注册 Dock 面板、不动 `MAIN_DOCK_VERSION`、用户既有布局不受影响；但要把"不可调高"修掉（P9） |
| Q2 | 改造范围 | **全部**：对话条 + 评审条 + 库级任务浮层 + 命令面板 AI 条目 |
| Q3 | 视觉规范范围 | **全局统一**：同时统一大纲 / 搜索 / 反链 / 标签等面板的间距与 hover 口径 |
| Q4 | 会话归属 | **保持按笔记归属**（`note_path`，`ai.rs:440`），切标签跟着切；不引入全局会话 |
