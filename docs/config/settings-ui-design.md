## 1. 背景与目标

### 1.1 现状

配置数据层已完备（三类配置项、默认值、校正、持久化、导入导出、即时生效），并已有一版**可用的设置对话框**：

- `Cmd-,` 打开模态对话框（宽 760px）：左栏三分类 + 右栏设置项 + 底部导入/导出/恢复默认
- 控件：开关、分段按钮（枚举）、步进器（数值）、预设字体按钮组
- 改动经 `update_config` 立即生效

**现有实现的不足**（本次设计要解决的）：

| # | 不足 | 影响 |
|---|---|---|
| P1 | 设置项平铺，**无分组、无搜索** | 配置项增多后难以定位（后续还会加"高级"类） |
| P2 | **未接入渲染的配置项**（行号、缩进等）与普通项外观一致 | 用户改了没反应，误以为是 Bug |
| P3 | **无单项重置**，只能整体"恢复默认" | 想撤销某一项必须全量重置 |
| P4 | 数值只能按步长点，**无法直接输入**；字体只能选预设 | 精确调整（如字号 13.5、任意字体）做不到 |
| P5 | 控件与配置是**一对一硬编码**，加一项要改多处 | 违背"易扩展"需求（C8.1） |
| P6 | 无"已修改/已生效"反馈，无变更说明 | 用户不确定改动是否保存 |

### 1.2 设计目标

| 目标 | 衡量方式 |
|---|---|
| G1 可查找 | 常用设置项 ≤ 3 次交互内可达；支持搜索 |
| G2 可理解 | 每项有标题 + 一句说明 + 取值范围；未生效项有明确标注 |
| G3 可精确调整 | 数值支持直接输入；字体支持系统字体列表 |
| G4 易扩展 | 新增配置项只需在数据描述表加一行，不改 UI 骨架 |
| G5 可回退 | 支持单项重置与整体重置 |
| G6 即时反馈 | 改动即时生效并给出轻量反馈；危险操作需确认 |

### 1.3 非目标

- 不做多配置档案（Profile）切换
- 不做配置云端同步
- 不做快捷键录制器（本期快捷键映射仍以文本/下拉呈现）
- 不做主题配色自定义（仅选择既有明暗与代码高亮主题）

## 2. 用户场景

| 场景 | 流程 | 关键诉求 |
|---|---|---|
| S1 首次调整外观 | `Cmd-,` → 基本 → 改主题/字号 → 立即看到界面变化 | 所见即所得，无需重启 |
| S2 找某个设置但忘了在哪 | `Cmd-,` → 在搜索框输入"行号" → 直接定位 | 搜索要快、能跳转 |
| S3 精确调字号 | 在字号输入框直接输入 `13.5` → 回车 | 支持直接输入而非只能点步进 |
| S4 改错了想撤回某一项 | 悬停该项 → 点击"恢复默认"图标 | 单项重置 |
| S5 备份/迁移配置 | 底部"导出配置" → 存 JSON；换机器后"导入配置" | 导入失败要有明确提示 |
| S6 遇到改了没反应的项 | 看到该项带"暂未生效"标记与说明 | 不误导用户 |

## 3. 信息架构

```
设置
├── 基本
│   ├── 外观（主题模式、界面语言）
│   └── 目录树（字体、字号、行高、字重、图标大小）
├── 编辑器
│   ├── 编辑行为（自动保存 + 延迟、缩进、行号）
│   ├── 字体与排版（字体、字号、行高）
│   └── 快捷键（映射列表）
└── 预览
    ├── 排版（字体、字号、行高、正文最大宽度）
    ├── 渲染（代码高亮主题、图片显示、链接打开）
    └── 同步（同步滚动）
```

- **三级结构**：分类 → 分组 → 设置项。分组只加一层，避免过深。
- **搜索**横跨全部设置项（标题 + 说明 + 分类名），命中后滚动定位并高亮。
- 未来新增"高级/插件"类时，直接加一个顶层分类即可。

## 4. 界面设计

### 4.1 呈现形式（决策点 D1）

| 方案 | 优点 | 缺点 |
|---|---|---|
| **A. 独立设置窗口**（推荐） | 可自由调整大小、可与主窗口并存对照（改字号能直接看主窗口变化）、空间充裕 | 需处理单例（重复打开聚焦已有窗口） |
| B. 模态对话框（现状） | 简单、聚焦 | 尺寸固定、遮挡主窗口，**看不到"即时生效"的效果** |
| C. 侧栏面板 | 与主界面一体 | 空间有限，不适合长列表 |

**推荐 A**：配置界面最有价值的反馈是"改完立刻在主窗口看到变化"，模态对话框恰好挡住了主窗口，与"即时生效"的核心卖点冲突。

### 4.2 布局线框（方案 A）

```
┌─ 设置 ────────────────────────────────────────────────────────┐
│ 🔍 [搜索设置…                                    ]              │
├──────────────┬────────────────────────────────────────────────┤
│ 基本          │  外观                                           │
│  ▸ 已选中     │  ┌──────────────────────────────────────────┐  │
│ 编辑器        │  │ 主题模式              跟随系统 ▾          │  │
│ 预览          │  │ 界面外观：跟随系统 / 浅色 / 深色          │  │
│              │  └──────────────────────────────────────────┘  │
│              │  ┌──────────────────────────────────────────┐  │
│              │  │ 界面语言              中文 ▾        ⟲     │  │
│              │  │ 界面文案语言                              │  │
│              │  └──────────────────────────────────────────┘  │
│              │                                                 │
│              │  目录树                                         │
│              │  ┌──────────────────────────────────────────┐  │
│              │  │ 字号              [−] [ 14 ] [+] px  ⟲   │  │

│              │  └──────────────────────────────────────────┘  │
```

- 顶栏：搜索框（常驻）
- 左栏：分类导航（宽 160px，选中态高亮）
- 右栏：按分组分段，组内为设置项卡片（可滚动）
- 底栏：备份迁移 + 整体重置 + 关闭

### 4.3 设置项行规范

每项由四部分组成：

| 元素 | 规范 |
|---|---|
| 标题 | 简短名词短语（≤ 8 字），如"目录树字号" |
| 说明 | 一句用途/影响说明；含取值范围或单位 |
| 控件 | 右对齐，宽度固定避免跳动 |
| 单项重置 ⟲ | **仅在值 ≠ 默认值时出现**，点击恢复该项默认 |
| 状态标记 | 未接入渲染的项显示 `⚠ 暂未生效` 徽标 + 说明中给出原因 |

### 4.4 控件规范

| 配置类型 | 控件 | 交互细节 |
|---|---|---|
| 布尔 | 开关 `Switch` | 受控：点击 → `update_config` → 重绘；禁用态用于联动项 |
| 枚举（≤4 项） | 分段按钮组 | 当前值高亮 |
| 枚举（>4 项，如代码主题） | 下拉选择 | 显示当前值，展开列表 |
| 数值（有区间） | **数字输入框 + 步进器** | 可直接输入；失焦/回车时校正到区间；步进按配置步长 |
| 数值（连续，如行高） | 滑块 + 数值显示 | 拖动即时预览 |
| 字体 | **系统字体下拉**（推荐） | 列出系统字体并**以该字体渲染字体名**预览；保留自由输入兜底 |
| 文本/映射（快捷键） | 文本输入或键值对列表 | 本期以只读列表 + 说明为主 |

> 决策点 D3：字体用"预设按钮组"（现状，实现简单）还是"系统字体下拉 + 预览"（体验好，需枚举系统字体）？**推荐后者**，字体是最需要所见即所得的设置。

### 4.5 搜索

- 匹配范围：标题 + 说明 + 分类/分组名，不区分大小写，支持中文子串。
- 结果：显示匹配项列表（标注所属分类），点击 → 切到对应分类并**滚动定位 + 短暂高亮**。
- 无结果：显示"未找到相关设置"空态。

### 4.6 反馈与确认

| 情况 | 处理 |
|---|---|
| 普通改动 | 立即生效，控件值直接变化（不需要"应用"按钮） |
| 输入越界 | 失焦时校正并**回显校正后的值**，避免静默篡改 |
| 恢复某项默认 | 无需确认，可再次修改 |
| 恢复全部默认 / 导入配置 | **二次确认**（会覆盖全部设置） |
| 导入失败 | 底部提示具体原因（文件不存在 / JSON 解析失败），保持现状 |
| 导出成功 | 轻量提示 + 显示文件路径 |

## 5. 状态与边界设计

| 状态 | 表现 |
|---|---|
| 默认 | 常规行 |
| 已修改（≠ 默认） | 出现 ⟲ 重置图标；标题可加细微强调（可选） |
| 依赖禁用 | 如"自动保存"关闭 → "保存延迟"置灰并说明"需先开启自动保存" |
| 暂未生效 | ⚠ 徽标 + 具体原因；**只在能力确实不可用时显示**（规则见 §5.1）；控件保持可用（值可保存/导出） |
| 搜索无结果 | 空态插图 + 文案 |
| 窗口窄（< 640px） | 左栏折叠为顶部横向标签 |

### 5.1 "暂未生效"徽标的显示规则

该徽标表示**能力缺失**，不表示"用户没打开"。判定规则：

| 情况 | 是否显示 |
|---|---|
| 能力确实不可用（框架无接口 / 引擎未接入 / 尚未接线） | ✅ 显示，并写明具体原因 |
| 能力可用，用户把开关关了 | ❌ **不显示**——这是用户选择，不是缺陷 |
| 能力可用，用户把开关开了 | ❌ 不显示 |

**文案必须与代码实际状态一致，不得凭印象书写**：

- 已接线的项必须移除标记（否则会误导用户以为功能坏了）；
- 已核实"框架有能力、只是我们没接线"的，写 **"尚未接线"**，不能写"框架不支持"；
- 真正确认框架无能力的，写清缺什么（如"检查引擎尚未接入"）。

当前带 ⚠ 的项（4 项）：`language`、`color_scheme`、`image_display`、`link_open`。
（`spell_check` 已于 2026-10-20 从配置模型与设置界面移除，不再计入。）

已移除标记的项：

| 配置项 | 移除原因 |
|---|---|
| 显示行号 | 编辑内核升级为 `EditorState` 后接线生效，能力始终可用 |
| 使用 Tab 缩进 / 缩进宽度 | `set_tab_size` 属 `impl<M: MultiLineMode>`，能力可用 |

**关于行号的表述**：本应用**同时具备编辑与预览**，不存在独立的"编辑模式 / 预览模式"之分
（原"默认编辑模式"配置项已移除，见 `config-wiring-design.md`）。
编辑区基于代码编辑器控件，行号是该控件的能力，**始终可用、开关即开即显**；
因此界面文案不得出现"仅某模式支持"这类暗示存在模式切换的表述。

## 6. 可访问性与键盘

- `Cmd-,` 打开/聚焦；`Esc` 关闭；`Cmd-W` 关闭（遵循 macOS 习惯）。
- `Tab` 在设置项间移动；控件内部方向键/空格可用（依赖组件库既有支持）。
- 每个控件有可朗读名称（标题即标签）。
- 不依赖颜色传达状态：徽标带文字（"暂未生效"）而非仅靠颜色。

## 7. 视觉规范

| 项 | 规范 |
|---|---|
| 窗口尺寸 | **宽度固定 720px；高度自适应内容**（见 [§7.1](#71-窗口尺寸自适应规则)），夹取到 220–860，超上限时内容区滚动 |
| 间距 | 区组内行间距 8px，分组间距 24px，页面内边距 16–20px |
| 字号层级 | 分组标题 13px 加粗 + 弱化色；设置项标题 13px；说明 11px 弱化色 |
| 颜色 | 全部取自当前主题 token；**不硬编码颜色**，自动适配明暗 |
| 图标 | 沿用配置里的 `icon_size`；重置 ⟲ / 警告 ⚠ 使用组件库图标 |
| 对齐 | 控件右对齐成列；数值类控件等宽，避免改值时布局跳动 |

### 7.1 窗口尺寸自适应规则

**问题**：窗口此前用 `WindowOptions::default()` 交由框架决定尺寸，打开时窗口偏大，内容上下留白明显。

| 维度 | 规则 |
|---|---|
| 宽度 | **固定** = 侧栏 160 + 内容列 560 = **720px**。有意固定：避免切换分类时控件列左右跳动 |
| 高度 | **自适应** = 搜索栏 45 + 底栏 48 + 内容区（16 + 可见项数 × 52 + 分组数 × 32） |
| 空态 | 无匹配项时内容区按 64px 计算 |
| 上下限 | 夹取到 **220 – 860**；超过上限时内容区滚动（**只有这种情况才出现滚动条**） |
| 触发时机 | 仅当"内容指纹"变化时重算：**打开窗口 / 切换分类 / 搜索过滤**（可见项数或分组数变化） |
| 不触发 | 仅修改某个配置值（不改变项数）时不重算 → 用户手动调大的窗口不会被立刻缩回 |

**实现依据**：框架未提供通用的"测量元素"API（gpui-pre 0.3.5 无 `App::measure`），无法在渲染前取得内容自然高度。
因此把各部分的高度固定为常量（`src/ui/settings.rs` 的 `mod layout`），窗口高度按可见项数**精确计算**，
再用 `Window::resize()`（设置内容区尺寸）回设。常量与实际渲染的行高一致 → 误差为零，无多余空白、无滚动条。

### 7.2 实时预览的交互行为

所有改动统一走 `app.rs::update_config`：改内存 → `sanitize` → 落盘 → `apply_theme` → `refresh_windows()`。
主窗口与设置窗口都在 `render` 中现读配置，因此**下一帧即见**，不需要"应用"按钮、不需要重开页面。

| 操作 | 立即看到的效果 |
|---|---|
| 切换主题 | 全部窗口配色即时变化 |
| 改目录树字号 / 字重 / 图标大小 | 主窗口文件树即时变化 |
| 改缩进宽度 / 使用 Tab 字符 | 编辑区按 Tab 的行为即时变化（已接线） |
| 打开"显示行号"开关 | 编辑区左侧立即显示行号；关闭则隐藏（能力始终可用，无"暂未生效"提示） |
| 改自动保存开关 / 延迟 | 下一次输入起生效（L2，防抖任务在触发时读取配置） |
| 数值输入越界 | 失焦后校正并回显校正值 |
| 导入配置 / 恢复默认 | 全部设置项与主窗口即时还原 |

- 设置窗口自身的控件值也每帧与配置同步（数值输入框在 `render` 中回写），导入/重置后同样立即回显；
- 尺寸变化（切换分类、搜索过滤）随渲染即时生效，无需重开窗口。

### 7.3 约束条件与例外

| # | 约束 | 说明 / 违反后果 |
|---|---|---|
| C1 | 行高必须固定 | 高度计算依赖 `layout::ROW_H` 等常量。若某项改为内容自适应高度而不同步更新计算，会出现滚动条或留白 |
| C2 | 说明文字保持单行 | 说明超长会溢出固定行高；新增设置项时说明须控制在单行内 |
| C3 | 高度上限 860px | 项数继续增长时改为内容区滚动；若要突破，需先取得屏幕可用高度再放宽 |
| C4 | 用户手动调整后的行为 | 手动调整后，只要不切换分类/搜索就不会被覆盖；切换分类时按新内容重算 |
| C5 | 宽度不自适应 | 有意设计，避免控件列跳动 |
| C6 | 框架限制 | gpui 无元素测量 API。将来若提供 `measure`，应改为"测量内容 + 精确贴合"，去掉对常量的依赖 |

## 8. 技术实现方案（草案）

### 8.1 元数据驱动（核心改动）

把"设置项"抽象成数据描述，UI 只负责渲染描述表，从根本上解决 P5（扩展性）：

```rust
/// 一项设置的描述：新增配置项只需在这里加一行
struct SettingField {
    id: &'static str,
    title: &'static str,
    desc: &'static str,
    group: &'static str,
    kind: FieldKind,          // Bool | Enum | Number | Font | Text
    /// 从配置里取值
    get: fn(&AppConfig) -> FieldValue,
    /// 把新值写回配置
    set: fn(&mut AppConfig, FieldValue),
    /// 是否尚未接入渲染（显示"暂未生效"）
    unavailable: bool,
    /// 依赖：返回 None 表示可编辑，Some(原因) 表示禁用
    disabled: Option<&'static str>,
}
```

- 分类/分组/行/搜索索引全部由这张表推导。
- 新增配置项 = 数据模型加字段 + 表里加一行（满足需求 C8.1）。
- 搜索索引在打开设置时构建一次。

### 8.2 组件与数据流

```
SettingsView { query, active_tab }
    ├─ 渲染：读 crate::app::config(cx) → 按 SettingField 表生成行
    └─ 写入：控件回调 → crate::app::update_config(cx, |c| field.set(c, v))
                              └─ 校正 → 落盘 → 主题 → refresh_windows()
```

- 现状的 `switch_row / choice_row / number_row` 保留为**底层控件**，由描述表驱动调用。
- 窗口单例：用全局弱引用记录已打开的设置窗口，重复触发时聚焦而非新建。

### 8.3 依赖禁用示例

```
自动保存 = 关  →  保存延迟：禁用，提示"需先开启自动保存"
```

通过 `FieldKind::Number { depends_on: ... }` 或 `disabled` 闭包表达。

## 12. 风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 组件库缺少下拉/系统字体枚举能力 | 阶段 2 受阻 | 先用分段按钮 + 预设列表兜底，保持接口一致后续替换 |
| 元数据表用函数指针，枚举项需静态构造 | 灵活性受限 | 枚举选项用 `fn() -> Vec<(值, 文案)>` 惰性生成（如代码主题列表） |
| 独立窗口需处理多窗口与单例 | 状态管理复杂 | 用全局 `WeakEntity` 记录；关闭时清空 |
| 搜索索引与描述表不同步 | 新增项搜不到 | 索引由同一张表推导，不手工维护 |

  换成 `InputState` + `Input` 并订阅 `InputEvent::Change`，输入即过滤；"清除"按钮同时清空输入态。
  跨分类命中已能自动切换分类。
