# 配置管理 — 需求文档

> 状态：已实现（2026-09-21）
> 配套文档：[`config-management-design.md`](./config-management-design.md)
> 相关总体需求：`REQUIREMENTS.md` 的 R2.2（自动保存）、R3.4（同步滚动）、R3.5（代码高亮）、R11（明暗主题）

---

## 1. 背景与目标

应用此前所有界面参数都是硬编码的：目录树字号、自动保存延迟、代码高亮主题、同步滚动等都无法调整。用户（尤其从 Obsidian 迁移来的）期望能按自己的习惯调整外观与编辑行为，并能备份/迁移自己的配置。

**目标**：提供一套完整的配置管理能力，覆盖**基本 / 编辑器 / 预览**三大类，参考 Obsidian 的分类与交互方式，做到：

1. 每项配置都有合理默认值，用户可自定义；
2. 改动**即时生效**，无需重启；
3. 支持配置的**导入 / 导出**，便于备份与迁移；
4. 数据结构清晰、易于扩展，新增配置项成本低。

---

## 2. 术语

| 术语 | 含义 |
|---|---|
| 配置项 | 一个可调参数，如「目录树字号」 |
| 分类 | 配置项的顶层分组：基本 / 编辑器 / 预览 |
| 即时生效 | 修改后无需重启应用，界面立即反映新值 |
| 校正（sanitize） | 载入/导入后把越界或空值夹回合法区间，而不是拒绝配置 |

## 3. 功能需求

### C1 配置分类与组织

| # | 需求 | 验收标准 |
|---|---|---|
| C1.1 | 配置按「基本 / 编辑器 / 预览」三类组织 | 设置界面左栏可见三个分类入口，切换后右栏显示对应设置项 |
| C1.2 | 分类与交互方式参考 Obsidian | 左栏分类 + 右栏设置项（标题 + 说明 + 控件）的两栏布局 |
| C1.3 | 提供统一入口打开设置 | `Cmd-,` 可打开设置对话框 |

### C2 基本配置

| # | 配置项 | 默认值 | 验收标准 |
|---|---|---|---|
| C2.1 | 主题模式（跟随系统 / 浅色 / 深色） | 跟随系统 | 切换后整个界面明暗立即变化 |
| C2.2 | 界面语言（中文 / English） | 中文 | 值可持久化（界面文案本地化见 C6.1） |
| C2.3 | 图标大小 | 16 px | 目录树与工具栏图标随值变化 |
| C2.4 | 目录树字体（字体类型） | 系统默认 | 文件列表字体随值变化 |
| C2.5 | 目录树字号 | 14 px | 同上，取值被限制在 8–72 px |
| C2.6 | 目录树行高 | 1.5 倍 | 行距随值变化，限制在 0.8–3.0 |
| C2.7 | 目录树字重（常规 / 中等 / 半粗 / 粗体） | 常规 | 文件名粗细随值变化 |

### C4 预览配置

| # | 配置项 | 默认值 | 验收标准 |
|---|---|---|---|
| C4.1 | 代码块高亮主题 | `base16-ocean.dark` | 可选 syntect 全部内置主题；填了不存在的主题名时退回默认而非崩溃 |
| C4.2 | 同步滚动 | 开 | 关闭后编辑区与预览区滚动互不干扰 |
| C4.3 | 图片显示（适应宽度 / 原始尺寸 / 不显示） | 适应宽度 | 值可持久化（渲染支持见 C6.4） |
| C4.4 | 链接打开（应用内 / 系统浏览器） | 应用内 | 值可持久化 |
| C4.5 | 预览字体 | 系统默认 | 预览正文随值变化 |
| C4.6 | 预览字号 | 14 px | 限制在 8–72 px |
| C4.7 | 预览行高 | 1.5 倍 | 限制在 0.8–3.0 |
| C4.8 | 正文最大宽度 | 0（不限） | 设为非 0 后正文区收窄并居中 |

### C5 默认值与合法性

| # | 需求 | 验收标准 |
|---|---|---|
| C5.1 | 每个配置项都有合理默认值 | 删除配置文件后应用以默认配置正常运行 |
| C5.2 | 数值型配置有合法区间 | 手工把字号改成 999 或 0，载入后被夹回 8–72 |
| C5.3 | 空值/非法值不得破坏界面 | 字体名或主题名为空时回填默认；`NaN` 回落到下限 |
| C5.4 | 配置文件损坏或缺失不得导致启动失败 | 缺失/损坏时回落默认配置，应用照常启动 |

### C6 即时生效

| # | 需求 | 验收标准 |
|---|---|---|
| C6.0 | 任何配置改动立即生效，无需重启 | 修改主题、字号、同步滚动后界面立即变化 |
| C6.1 | （限制）界面语言 | 当前 UI 文案尚未本地化，语言项仅持久化，不切换文案 |
| ~~C6.2~~ | ~~（限制）默认编辑模式~~ | **已取消**：随 C3.1 一并移除（2026-09-24） |
| C6.3 | （限制）行号显示 | 当前编辑区为纯文本多行控件，行号仅代码编辑模式支持 |
| C6.4 | （限制）图片显示 / 链接打开 | 预览控件未暴露对应渲染开关与链接点击回调 |

### C7 导入 / 导出

| # | 需求 | 验收标准 |
|---|---|---|
| C7.1 | 导出当前配置为 JSON 文件 | 弹出系统保存对话框，文件可被再次导入 |
| C7.2 | 从 JSON 文件导入配置 | 弹出系统打开对话框，导入后立即生效并落盘 |
| C7.3 | 导入失败不得破坏现有配置 | 文件不存在、JSON 损坏时报错并保持当前配置不变 |
| C7.4 | 导入的外部 / 残缺文件可容错 | 只含无关字段的文件按默认配置处理，不报错 |

### C8 可扩展性与兼容性

| # | 需求 | 验收标准 |
|---|---|---|
| C8.1 | 新增配置项成本低 | 在对应分类结构体加一个带默认值的字段 + 设置界面加一行即可 |
| C8.2 | 旧配置文件向前兼容 | 只有部分字段的旧配置可正常载入，缺失字段回落默认 |
| C8.3 | 未知字段不影响解析 | 配置文件里出现已删除/未知的字段时忽略而非报错 |

## 4. 非功能需求

| 类别 | 要求 |
|---|---|
| **性能** | 配置读取只在启动时一次；渲染时读取的是内存副本，不产生文件 IO；结构体很小，克隆开销可忽略 |
| **可靠性** | 配置写入失败只打印告警，不影响编辑与保存主流程；解析失败一律回落默认值 |
| **可维护性** | 数据模型与 UI 解耦：`core/config.rs` 不依赖任何 GPUI 组件，可独立单测 |
| **可扩展性** | 新增配置项只需改数据模型 + 设置界面两处；枚举新增变体时编译器会强制补齐映射 |
| **一致性** | 分类、默认值、交互方式对齐 Obsidian；默认值与总体需求（`REQUIREMENTS.md`）保持一致 |

---

## 5. 明确的非目标

- 不做云同步配置（数据安全要求：不做任何云端上传）
- 不做多配置档案（Profile）切换
- 不做插件各自的配置体系（插件系统本身在 `REQUIREMENTS.md` P2 之外）

## 6. 验收清单

启动应用并按 `Cmd-,` 打开设置，逐项确认：

- [ ] 左栏显示「基本 / 编辑器 / 预览」，切换正常
- [ ] 修改**主题模式** → 界面明暗立即切换
- [ ] 修改**图标大小 / 目录树字号 / 行高 / 字重** → 文件树立即变化
- [ ] 修改**编辑器字体 / 字号 / 行高** → 编辑区立即变化
- [ ] 关闭**自动保存** → 输入后不再自动写盘，但**预览仍在刷新**
- [ ] 修改**代码高亮主题** → 预览代码块配色立即变化
- [ ] 关闭**同步滚动** → 滚动编辑区时预览不再跟随
- [ ] 修改**正文最大宽度** → 预览正文收窄并居中
- [ ] 点击**导出配置** → 生成 JSON 文件；再**导入**该文件 → 配置还原
- [ ] 点击**恢复默认** → 所有项回到默认值
- [ ] 删除 `~/Library/Application Support/xink/config.json` 后重启 → 应用以默认配置正常启动
- [ ] 手工把配置里的字号改成 `999` 后启动 → 被夹回 `72`，界面正常
