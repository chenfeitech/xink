# 显示隐藏文件 & 引用其他文件 — 设计方案

> 状态：**待确认**（2026-10-12）· 确认后再开发
> 范围：`src/core/vault.rs`（扫描规则）、`src/core/config.rs`（开关）、`src/ui/file_tree.rs`（菜单）

---

## 1. 现状

`core/vault.rs:97`：

```rust
pub fn should_ignore(name: &str) -> bool {
    matches!(name, ".git" | "node_modules" | "target" | ".DS_Store")
        || name.starts_with('.')        // ← 所有点开头的文件/目录
        || name.ends_with(".md.tmp")    // ← 应用自己的临时文件
}
```

所以 `.gitignore`、`.obsidian/`、`.env` 这类**在目录树里完全看不到**，也就无法引用它们。

## 2. 建议：把"隐藏"拆成两类区别对待

| 类别 | 例子 | 建议 | 理由 |
|---|---|---|---|
| **点开头的隐藏项** | `.gitignore` `.obsidian/` `.env` `.editorconfig` | **默认显示** | 这正是你要"能看到"的东西，通常数量不多 |
| **大体积噪音目录** | `.git` `node_modules` `target` | **始终跳过** | 展开后节点数以万计，会把扫描和渲染拖垮 |
| **应用临时文件** | `*.md.tmp` | **始终跳过** | 是应用自己产生的中间产物，显示出来只会干扰 |

> 如果你确实需要看到 `.git` / `node_modules` 里的内容，我可以再加一个独立开关，
> 但默认必须关闭——否则打开库就会卡住。

## 3. 配置项

```rust
pub struct BasicConfig {
    ...
    /// 目录树是否显示点开头的隐藏文件/目录（默认 true）
    pub show_hidden: bool,
}
```

- 默认 **true**（按你的要求"显示所有文件"）；
- 改完走 `update_config` → 重新扫描 → 即时生效；
- 设置页「目录树」分组新增该项。

`should_ignore` 相应改为带参数：

```rust
pub fn should_ignore(name: &str, show_hidden: bool) -> bool
```

噪音目录与临时文件**不受该开关影响**（始终跳过）。

## 4. 引用其他文件（第二部分需求）

目录树右键菜单新增两项，都是纯逻辑、可单测：

| 菜单项 | 行为 |
|---|---|
| **复制相对路径** | 复制相对**当前笔记所在目录**的路径，如 `../assets/a.png` |
| **复制为 Markdown 链接** | 图片 → `![](相对路径)`；其余 → `[文件名](相对路径)`；目录 → 只复制路径 |

这样一来，在笔记里 `Cmd+V` 就能直接粘出可用的引用，不需要手打路径。

> 未做（成本较高，可作为后续项）：「直接插入到当前笔记光标处」——需要跨面板
> 拿到活动编辑器并操作选区，涉及面板间通信，不属于本次范围。

## 5. 约束与风险

| # | 项 | 说明 |
|---|---|---|
| R1 | 性能 | 显示隐藏项会增加扫描量；`.obsidian` 之类通常不大，可接受。打开库时若明显变慢需再评估 |
| R2 | 误操作 | 隐藏文件往往不建议手改（如 `.obsidian` 配置）；显示为普通条目即可，不加特殊提示 |
| R3 | 相对路径基准 | 无打开笔记时，相对路径退化为**相对库根目录**，避免复制出无法解析的路径 |
| R4 | 链接转义 | 路径含空格/中文时用尖括号包裹：`[a b](<a b.png>)`，否则 Markdown 解析会断 |

## 6. 验收

1. 打开库后能看到 `.gitignore`、`.obsidian` 等点开头的条目
2. `.git` / `node_modules` / `target` 仍然不出现（避免卡死）
3. 设置里关掉"显示隐藏文件" → 这些条目消失，且无需重启
4. 右键一个图片 → 「复制为 Markdown 链接」→ 在笔记里粘贴得到 `![](相对路径)`，预览能显示
5. 路径含空格/中文时粘贴出的链接仍可解析
6. 没有打开任何笔记时复制路径，得到的是相对库根的路径

## 8. 决策与实施（2026-10-12）

**决策**：
- `.git` / `node_modules` 不显示 ✓
- 复制路径**与**「直接插入到当前笔记」都要 ✓
- 隐藏项加视觉标记（淡化显示）✓

### 8.1 一个重要发现：原本只扫描 md 与图片

`scan_dir` 的收集条件原本是 `is_markdown || is_image_path`——**其他类型文件压根不进树**。
所以"显示所有文件"要改的是这一层，而不只是隐藏规则。

### 8.2 最终实现

- 配置 `basic.show_all_files`（**默认 true**）：
  - true → 所有文件与目录都进树，含点开头的隐藏项；
  - false → 退回原行为（只显示笔记与图片）。
- `should_ignore(name, show_all)`：`.git` / `node_modules` / `target` / `.DS_Store`
  与 `*.md.tmp` **始终跳过**，不受开关影响。
- 隐藏项（点开头）在树里用 `muted_foreground` 淡化显示。
- 右键菜单新增三项：
  - **复制相对路径**：相对当前活动笔记所在目录；无打开笔记时相对库根；
  - **复制为 Markdown 链接**：图片 `![]()`、其余 `[]()`，路径含空格/括号时用 `<>` 包裹；
  - **插入到当前笔记**：通过 `AppState.tabs` 拿到活动编辑面板，在光标处插入
    （新增 `EditorPanel::insert_at_cursor`，插入后走与输入相同的同步链路）。
- 设置页「目录树」新增该开关。

单测：扫描可见性（隐藏项/噪音目录/开关两端）、`relative_path`（同级/下级/上级）、
`markdown_link`（图片/普通/含空格），共 **155 passed**；clippy 0 error。

**待人工验收**：
1. 打开库能看到 `.gitignore`、`.obsidian` 等（淡化显示），`.git`/`node_modules` 仍不出现

4. 设置里关掉开关 → 非笔记/图片文件消失，无需重启
