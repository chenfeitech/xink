# 人工验收清单

> 代码合进去了 ≠ 做完了。这份文档把散落在各设计文档 §「人工验收清单」里的条目
> 收敛到一处，照着跑一遍就能把"已完成"变成**真的完成**。
>
> 用法：装一个 release 或 debug 包（别用没跑过的分支）→ 按本文顺序过一遍 →
> 通过的在 `- [ ]` 里打 `x` 并填日期 → 没通过的**直接开 bug 或回到对应文档**，
> 不要顺手放过。
>
> 图例：✅ 已验收（填日期）/ ❌ 未通过（写清现象）/ ➖ 本次跳过（写清原因）。
> 每条都尽量写明"不通过怎么办"，指向对应文档的章节。

## 1. 编辑区 Markdown 语法高亮

来源：`docs/editor/editor-syntax-highlight-eval.md` §5

- [ ] 打开一篇 `.md`：标题 `#`、粗体 `**`、行内代码、链接、列表符号都有着色
- [ ] ```json 代码块：编辑区有着色（切到预览区也应有）
- [ ] ```yaml 代码块：同上
- [ ] 打开 `.json` / `.yaml` / `.toml`：仍按各自语言高亮（回归）
- [ ] 打开 `.txt` 或未知扩展名：纯文本，无着色
- [ ] **先打开 json 再打开 md：不残留 json 配色**（面板复用场景，最易翻车）
- [ ] 切到浅色主题：着色跟随，无"深色残留"
- [ ] 几百行含多个代码块的笔记：滚动与输入不卡

装饰层：

- [ ] `#` 与列表符号 `-` / `1.` 淡化但不消失
- [ ] 链接文字有下划线，括号与 URL 不带下划线
- [ ] `>` 块引用标记**有颜色**（不是竖线 —— 竖线框架做不出来，别按竖线验收）
- [ ] 围栏代码块里写 `# 注释` / `- 项`：不被装饰
- [ ] 编辑标题时装饰跟随（防抖结束后），不错位
- [ ] 切到 json / yaml：不应有 Markdown 装饰
- [ ] 关闭标签后新建空白页：不残留上一篇的装饰

不通过怎么办：先确认是"着色"还是"装饰"的问题 → `editor-syntax-highlight-eval.md` §6 有
一整节已知取舍（是否加整篇高亮开关、两端主题不一致等），先读再改。

## 3. 编辑区滚轮

来源：`docs/editor/editor-scroll-wheel.md` §4

**前置分诊**（先做这一步，能省一半时间）：设置 → 预览 → 关掉「同步滚动」→ 再滚编辑区。
恢复正常 ⇒ 根因是同步写入；仍异常 ⇒ 框架侧 / 容器问题。

- [ ] **滚到文档末尾：最后一行贴在视口底部，后面没有可滚的空白**
- [ ] 内容不足一屏时滚不动：正确行为，不是 bug
- [ ] 鼠标停在行号区 / 滚动条 / 四角上滚轮：都能滚
- [ ] 上下滚：方向正确、连续、不跳
- [ ] 快速甩动触控板：惯性顺滑，松手后**不被拉回**（核心）
- [ ] 滚到顶 / 滚到底：停在边界，不出现空白或回弹
- [ ] 滚动中点击定位光标、拖选文字：不受影响
- [ ] 中文输入法候选框出现时滚动：不打断预编辑
- [ ] **拖动滚动条**：能拖、跟手；拖动中预览跟随且不被反向拉回
- [ ] 触控板两指上下滑：方向与系统一致，惯性自然衰减
- [ ] 长文档（几百行 + 代码块）快速滚：不掉帧
- [ ] 开着「同步滚动」滚编辑区：预览跟随
- [ ] 滚预览时编辑区跟随；交替滚动时最后一次手势生效
- [ ] 勾选 / 取消「软换行」：滚动位置不乱跳
- [ ] 开 HUD（`preview.debug_scroll_sync`）：停止滚动后 `Δ` 收敛

## 4. 滚动同步（标题锚点）

来源：`docs/preview/scroll-sync-design.md` §6

- [ ] 滚编辑区：预览停在**同一个标题 / 段落**（不是"差不多"）
- [ ] 滚预览：编辑区顶部是**同一行源码**
- [ ] 含 50 行 ```python 块的笔记：两端对齐（R1 的验收点）
- [ ] 含大图片的笔记：图片加载完成后不漂移
- [ ] 快速甩动、连续来回滚：无抖动、无跳回
- [ ] 两端交替滚动：最后一次手势生效
- [ ] 开 3 个标签：只有活动标签带动预览
- [ ] 切标签 / 新开笔记：不跳到旧位置
- [ ] 编辑文字后（300ms 防抖重解析）：预览重新对齐到正在编辑的位置
- [ ] 数据文件（json）：百分比同步，行为与现在一致
- [ ] 关掉「同步滚动」：两端完全独立

## 5. 预览滚动抖动

来源：`docs/preview/preview-scroll-jitter.md` §4

默认 `realtime`：滚动中对端持续跟随。若切 `on_stop`，预期变成**滚动中对端不动，
停下约 0.25 秒后对端跳到对应位置**。

- [ ] **滚编辑区：预览跟随，不停在原地、不整块跳动**（最核心的一条）
- [ ] 滚预览：编辑区同样跟随，方向一致、不来回推
- [ ] 长文档连续滚：被滚的一侧完全平稳，无上下跳 / 微调
- [ ] 快速甩动后松手：惯性自然衰减，松手瞬间不"弹一下"
- [ ] 滚过图片：加载完成后位置不跳（允许一次性纠正，不应反复跳）
- [ ] 滚过大表格 / 长代码块边界：不整块跳动
- [ ] 滚动条拖动：跟手，thumb 不跳
- [ ] 交替滚动：只有一侧跟随，不来回推
- [ ] HUD 看 `Δ`：收敛到 1 行内
- [ ] 仍有抖动 → 设置里把「同步时机」切成 `on_stop`，重跑前 4 条
- [ ] 切标签 / 开新笔记：预览立刻对齐一次
- [ ] 开 HUD：停止滚动后 `Δ` 收敛且稳定

不通过怎么办：§6 遗留项 —— 升级 gpui-kit 0.8.0 后 `set_scroll_offset` 的 deferred 语义
与虚拟列表测量要重新核对，同步参数可能得重调。

## 10. AI 修订评审条（逐块接受 / 拒绝）
