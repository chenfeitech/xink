# 需求：JSON / YAML 等文本文件在线编辑

## 背景

xink 目前只能编辑 `.md`（`src/ui/tabs.rs:182` 直接把非 Markdown 挡在门外），
库里的 `config.json`、`*.yaml` 之类的配置文件只能看、不能改、也不能预览。
用户希望能像编辑笔记一样直接打开这些数据文件，并且右侧预览给出
**格式化（pretty-print）之后的语法高亮结果**，编辑时给出即时的格式校验与错误提示。

## 非目标（本期不做）

- 移动端适配：GPUI 是桌面框架，无移动端渲染后端。
- JSON Schema / YAML Schema 语义校验。
- 结构化树形编辑（折叠节点、表格化编辑键值）——预览一律用代码块形态。
- 写回格式化结果（见 R13.6）。
- 上传到服务端 / 多人协同：本地优先，文件真值在磁盘。
- 视频预览（见 R13.10 与 `json-yaml-editing-design.md` §9）。

## 验收口径

- 打开一个 JSON：编辑区出现语法高亮，右栏出现缩进 2 空格、高亮的格式化结果。
- 故意打错一个逗号：状态栏 / 编辑区提示出错行号列号，预览给出错误提示而不崩。
- 改完 300ms 后自动落盘；`Cmd+S` 立即落盘；磁盘内容与编辑器一致。
- 关掉再打开：文件在目录树中仍可见（不需开"显示全部"）。
