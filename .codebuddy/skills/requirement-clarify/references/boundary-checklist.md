# 边界条件清单（九项）

需求澄清时逐条过，标注「适用 / 不适用 / 要人工验」。
**适用项必须写进需求文档 §4「边界与约束」**，并说明处理方式。

| # | 边界项 | 本项目的典型判据 | 依据 |
|---|---|---|---|
| 1 | 空输入 | 空笔记、空库、空搜索词、空标签 | — |
| 2 | 超大输入 | 10MB 级 `.md`、万级文件的库；Rope 而非 String；索引放后台 | `../../../rules/04-notes-domain.md` §5 |
| 3 | 非法路径 | 路径不存在、越界跳出库根、含 `..` | — |
| 4 | 并发写 | 用户同时用 Vim / Obsidian 改同一文件是**合法场景** | `../../../rules/04-notes-domain.md` §1 推论 |
| 5 | 外部程序改文件 | `notify` 事件 + mtime 比对；`dirty == true` 时必须弹提示，绝不静默覆盖 | `../../../rules/04-notes-domain.md` §4 |
| 6 | 崩溃后半截文件 | 写盘必须 temp + 同目录 rename；写失败必须提示 | `../../../rules/04-notes-domain.md` §2 |
| 7 | 多库切换 | 切换 Vault 时状态、标签、索引的处置 | `../../../../docs/vault/multi-vault-design.md` |
| 8 | 隐藏与忽略文件 | `.git` / `node_modules` / `.` 开头 / `*.md.tmp` | `../../../rules/04-notes-domain.md` §7 |
| 9 | 非 UTF-8 | 读写失败要给出明确错误，不得 panic | `../../../rules/04-notes-domain.md` §8 |

## 补充：本项目特有的两类「测不了」

这两类不进自动化测试，但需求文档必须写明归属：

| 类别 | 例子 | 归属 |
|---|---|---|
| 渲染 / 手感 / 着色 | 滚动手感、语法高亮配色、气泡靠哪边 | 登记到 `docs/ACCEPTANCE.md` 人工验收 |
| 写真实用户目录 / 发真实 HTTP | `app_data_dir()`、模型连接探测 | **抽出纯规则函数测**，函数本身留人工 |
