# 笔记应用领域规则

## 1. 磁盘上的文件是唯一真值

- 笔记正文的唯一真值是磁盘上的 `.md` 文件，应用只是它的一个视图
- **任何索引、缓存、内存状态都是可重建的派生数据**
- 绝不把笔记正文写进索引文件；索引随时删除都能重建
- 不引入数据库，不使用专有二进制格式

推论：用户用 Vim / Obsidian 改同一个文件是**合法场景**，不是异常情况。

## 2. 写盘必须原子

直接 `write` 会在崩溃时留下半截文件——笔记应用最严重的 bug。

```rust
// 正确：写临时文件再 rename（同分区 rename 是原子的）
fn atomic_write(path: &Path, content: &str) -> Result<()> {
    let tmp = path.with_extension("md.tmp");
    fs::write(&tmp, content)?;
    fs::rename(&tmp, path)?;   // 原子替换
    Ok(())
}

// 错误
fs::write(path, content)?;     // 崩溃即损坏用户笔记
```

补充：
- 临时文件必须写在**同一目录**（同文件系统 rename 才原子）
- 保存成功后更新 `disk_mtime`，避免被自己的写入触发"外部修改"提示
- 保存失败必须向上报错并提示用户，**绝不静默丢弃**

## 3. 保存策略

- 自动保存：停止输入 **300ms** 防抖后触发
- `Cmd+S` 立即保存
- 关闭标签 / 退出应用前，若 `dirty` 为真必须保存或提示
- `dirty` 标记在保存成功后清除

## 4. 外部变更：提示，绝不静默覆盖

用 `notify` 监听库目录，事件到达后：

1. 比对文件 `mtime` 与内存中的 `disk_mtime`
2. mtime 变化 **且** 当前笔记 `dirty == false` → 自动重新加载（用户未编辑，安全）
3. mtime 变化 **且** 当前笔记 `dirty == true` → **弹提示让用户选择**（重新加载 / 保留我的修改 / 另存为）
4. 绝不静默覆盖用户未保存的编辑

- 监听要忽略应用自己写盘触发的事件（靠 mtime 比对 + 短暂静默窗口）
- 监听要忽略临时文件（`.md.tmp`）与忽略目录（`.git`、`node_modules`）

## 5. 大文件与大库

- 笔记内容用 **`Rope`**（`ropey`），禁止用 `String` 存全文后反复拷贝/拼接
- 索引构建放 `cx.background_spawn()`，不阻塞 UI
- 文件树子目录**懒加载**：只在展开时读取该层
- 预览更新用 `TextViewState::set_text()` 增量更新，不重建整个文档

## 6. 性能防抖基线

| 场景 | 防抖/策略 |
|---|---|
| 编辑 → 预览刷新 | 300ms |
| 编辑 → 自动保存 | 300ms |
| 编辑 → 索引重建 | 500ms（比保存更长，避免频繁重建） |
| 搜索输入 → 查询 | 200ms |

## 7. 忽略规则

默认从文件树与索引中排除（后续做成可配置）：

- `.git`、`node_modules`、`target`、`.DS_Store`
- 以 `.` 开头的隐藏文件与目录
- 应用自身产生的临时文件（`*.md.tmp`）

## 8. 编码与路径

- 全部按 **UTF-8** 读写，读写失败要给出明确错误而非 panic
- 内部统一用 `PathBuf` 存储路径，只在显示时转字符串
- 图片引用支持相对路径（相对笔记所在目录）与网络 URL；网络图片加载要超时降级

## 9. Markdown 方言

- 基线：CommonMark + GFM（表格、任务列表、删除线、自动链接）
- 双链 `[[笔记名]]` 与标签 `#tag` 是**本项目扩展**，不属于 GFM，需自行解析
- 不做所见即所得（WYSIWYG）编辑：本产品是**源码编辑 + 分屏实时预览**
