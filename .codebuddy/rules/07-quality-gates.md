# 质量门禁

> 用法：阶段结束 → 跑对应门禁 → **机器项** AI 自判、结果贴进状态文件；
> **人工项**（标注 👤）必须交回用户，AI 不得自行放行。

## 门禁总表

| 门禁 | 阶段 | 性质 | 未过的后果 |
|---|---|---|---|
| G1 | 需求澄清 | 机器 + 👤拍板项清零 | 不得进设计 |
| G2 | 方案设计 | 机器 + 👤用户确认 | 不得动 `src/` |
| G3 | 研发计划 | 机器 | 不得开工 |
| G4 | 实施研发（每任务） | 机器（4 条命令） | 不得提交 |
| G5 | 测试验证 | 机器 | 不得交付 |
| G6 | 质量保障 | 机器 + 👤人工验收 | 不得结项 |

---

## G1 需求门禁

- [ ] `docs/<slug>-requirements.md` 存在
- [ ] 含 目标 / **非目标** / 边界条件 / 验收标准 四节
- [ ] 每条需求有唯一 `R-n` 编号
- [ ] 现状描述附 ≥1 处 `文件:行号` 证据（禁止"应该是"，历史教训见 `05-design-first.md` §4）
- [ ] 「待用户拍板」清单已清空 👤

## G2 设计门禁

- [ ] `docs/<slug>-design.md` 十章齐全（模板见 `05-design-first.md` §2）
- [ ] 被否决方案 ≥1 个且附理由
- [ ] 数据模型章节写明持久化格式与旧数据兼容
- [ ] 测试计划区分「能自动化」与「要人工」
- [ ] 需用户拍板的开放问题已单独列出
- [ ] **用户已确认** 👤

## G3 计划门禁

- [ ] `docs/exec-plans/<slug>.md` 存在
- [ ] 每个任务有 `T-n` 编号、前置依赖、**验收命令**
- [ ] 每个任务能独立编译通过（不存在"全做完才能编"的任务）
- [ ] 每个 P0 任务关联 ≥1 条 `R-n`

## G4 实施门禁（每个任务提交前）

四条命令必须全绿，且**输出摘要贴进状态文件**：

```bash
cargo build                     # warning 数为 0
cargo clippy --all-targets      # 无 warning
cargo fmt --check               # 无 diff
cargo test                      # 全绿
```

- [ ] 上述 4 条全绿
- [ ] `git diff --stat` 与计划「涉及文件」一致，超出部分已说明原因
- [ ] 新增的 `core/` 逻辑有 `#[test]` 覆盖
- [ ] 提交粒度 = 1 个任务（见 `06-git-workflow.md`）

## G5 测试门禁

- [ ] 新增 / 修改的 `core/` 模块已建 `tests/<层>/<模块>.rs` 并 `#[path]` 挂载
- [ ] 边界九项（空输入 / 超大输入 / 非法路径 / 并发写 / 外部程序改文件 / 崩溃后半截文件 / 多库切换 / 隐藏与忽略文件 / 非 UTF-8）
      逐条标注「已测 / 要人工 / 不适用」并注明理由
- [ ] `cargo test` 全绿
- [ ] 无测试写真实用户目录（检查是否硬编码 `app_data_dir()`）

## G6 质量门禁

- [ ] 代码自审清单全过（分层方向、错误处理分层、命名、注释、无 `unwrap`）
- [ ] `clippy` + `fmt` 干净
- [ ] 无 **Blocker** 级缺陷遗留（丢数据 / 崩溃 / 编译不过）
- [ ] 人工验收项已登记进 `docs/ACCEPTANCE.md`，并明确告知用户"这些要你亲自看" 👤
- [ ] `docs/INDEX.md` 已回写（新文档登记 + 状态 + 已知缺口）
- [ ] 状态文件六阶段全 ✅

## 缺陷分级

| 级别 | 定义 | 处理 |
|---|---|---|
| **Blocker** | 丢数据、崩溃、编译不过 | 当次必修，不得交付 |
| **Major** | 功能不符需求、明显性能问题 | 记为新任务，下轮修 |
| **Minor** | 体验瑕疵、命名、文档漂移 | 记入 `docs/INDEX.md` §10 |
| **Won't fix** | 明确不做 | 写进设计文档「非目标」 |

## 豁免

仅缺陷修复可跳过 G1 / G2，条件与后续要求见 `00-pipeline.md` §4。
**G4 / G5 / G6 任何情况下不豁免。**
